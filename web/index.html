How it works

Trained from scratch

A GPT-style transformer written in PyTorch and trained on a laptop, using short stories written in a young child's vocabulary. No pretrained weights.

Guessing the next token

The model only ever answers one question: given the story so far, how likely is each possible next token? A token is a common word or a piece of a rarer one. The bars show its answer, and one token is drawn from them.

Running in your browser

The tokenizer and the transformer are re-implemented in plain JavaScript with no libraries. Nothing you type leaves this page.
